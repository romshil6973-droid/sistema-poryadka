# Как добавить продукт на витрину

Витрина на лендинге собирается из одного файла — `catalog/products.json`. Страницу править не нужно: добавили запись → продукт появился в разделе «Продукты» и в фильтрах «Бесплатные / Платные».

## Шаги

1. Если есть скриншот — положите его в `assets/products/<id>.jpg` (ширина ~1600 px, JPEG).
2. Добавьте запись в массив `products` в `catalog/products.json` (образец ниже). Порядок в файле = порядок на странице.
3. Проверьте: `node scripts/check-catalog.mjs`. Он скажет, если что-то забыто.
4. Закоммитьте и отправьте — сайт обновится сам.

## Образец

```json
{
  "id": "tabel",
  "name": "Табель",
  "kind": "free",
  "price": "Бесплатно",
  "status": "available",
  "featured": false,
  "tagline": "Учёт рабочего времени без Excel",
  "description": "Одна-две фразы: что делает и для кого.",
  "features": ["До четырёх коротких пунктов", "…"],
  "platforms": ["Windows 10", "Windows 11"],
  "meta": "Версия 1.0.0 · 90 МБ",
  "image": "assets/products/tabel.jpg",
  "imageAlt": "Окно программы «Табель» со списком сотрудников",
  "action": { "label": "Скачать для Windows", "href": "https://github.com/romshil6973-droid/sistema-poryadka/releases/download/tabel-v1.0.0/Tabel-Setup-1.0.0.exe" }
}
```

## Поля

| Поле | Обязательно | Что писать |
| --- | --- | --- |
| `id` | да | Латиница, цифры, дефис: `tabel`, `kpi-dashboard`. Не меняется после публикации. |
| `name` | да | Название продукта, как в программе. |
| `kind` | да | `free` — бесплатный, `paid` — платный. |
| `price` | да | Как показать цену: «Бесплатно», «По запросу», «от 3 000 ₽ в месяц». |
| `status` | да | `available` — можно скачать или заказать; `soon` — карточка с пометкой «Скоро», кнопка неактивна. |
| `featured` | нет | `true` — показать крупно со скриншотом. Только у одного продукта, и только если есть `image`. |
| `tagline` | да | Одна фраза: зачем продукт. |
| `description` | нет | Одно-два предложения. |
| `features` | нет | До 4 коротких пунктов. |
| `platforms` | нет | Где работает. |
| `meta` | нет | Версия, размер и т. п. — мелким текстом под кнопкой. |
| `image`, `imageAlt` | нет | Скриншот и его описание (для незрячих и поисковиков). |
| `action.label` | да | Текст кнопки: «Скачать для Windows», «Запросить демо», «Запросить пилот». |
| `action.href` | для `available` | Бесплатный — ссылка на файл в GitHub Releases; платный — `#contact` (форма заявки) или страница продукта. |

## Правила витрины

- Бесплатные продукты — кнопка золотая («скачать»), платные — нейтральная («запросить»).
- Каждая программа на витрине должна быть приведена к стандарту бренда: `sistema-poryadka-brand/CHECKLIST.md`.
- Тот же `catalog/products.json` смогут читать программы — для блока «Другие продукты «Системы Порядка»». Поэтому ссылки в `action.href` — полные (`https://…`) у всего, что ведёт наружу.
