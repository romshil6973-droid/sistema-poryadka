# Как добавить продукт на витрину

Витрина на лендинге собирается из одного файла — `catalog/products.json`. Каждый продукт — баннер: картинка или знак, название, короткое описание, список «что умеет» и одна кнопка. Страницу править не нужно.

## Шаги

1. Если есть скриншот — положите его в `assets/products/<id>.jpg` (ширина ~1600 px, JPEG). Без скриншота на баннере будет знак «Системы Порядка». Новые иконки для витрины не рисуем: отличие карточек — подпись `markLabel` и цвет `accent`.
2. Добавьте запись в массив `products` в `catalog/products.json`. Порядок в файле = порядок на странице.
3. Проверьте: `node scripts/check-catalog.mjs`. Он скажет, если что-то забыто или текст не помещается.
4. Закоммитьте в ветку и откройте PR в `main`. GitHub Pages отдаёт корень `main` и обновляет сайт после мёржа.

## Образцы

Бесплатный:

```json
{
  "id": "tabel",
  "name": "Табель",
  "kind": "free",
  "price": "Бесплатно",
  "status": "available",
  "tagline": "Учёт рабочего времени без Excel",
  "description": "Одно-два предложения: что делает и для кого.",
  "meta": "Windows 10 и 11 · 90 МБ",
  "image": "assets/products/tabel.jpg",
  "imageAlt": "Окно программы «Табель» со списком сотрудников",
  "action": { "label": "Скачать бесплатно", "href": "https://github.com/romshil6973-droid/sistema-poryadka/releases/latest" }
}
```

Платный:

```json
{
  "id": "primer-platny",
  "name": "Пример",
  "kind": "paid",
  "price": "По запросу",
  "status": "available",
  "tagline": "Одна фраза, зачем продукт",
  "action": { "label": "Записаться на ранний доступ", "href": "#offer" }
}
```

В разработке, с письмом о запуске (кнопка активна):

```json
{
  "id": "zaslon",
  "name": "Заслон",
  "status": "soon",
  "tagline": "Согласование служебных записок: от заявки до подписанного PDF",
  "description": "Два-три коротких предложения, вместе до 360 знаков.",
  "features": [
    "Подача служебной записки в браузере и настраиваемый маршрут",
    "Подпись шага и PDF с отметками"
  ],
  "markLabel": "ЗС",
  "accent": "#355c8a",
  "action": {
    "label": "Сообщить о запуске",
    "href": "mailto:R.SH.69.73@yandex.ru?subject=%D0%97%D0%B0%D1%81%D0%BB%D0%BE%D0%BD%20%E2%80%94%20%D1%81%D0%BE%D0%BE%D0%B1%D1%89%D0%B8%D1%82%D0%B5%20%D0%BE%20%D0%B7%D0%B0%D0%BF%D1%83%D1%81%D0%BA%D0%B5"
  }
}
```

В разработке без кнопки (кнопка неактивна и подписана «Скоро»):

```json
{ "id": "primer", "name": "Пример", "status": "soon", "tagline": "Короткая фраза, зачем продукт" }
```

## Поля

| Поле | Обязательно | Что писать |
| --- | --- | --- |
| `id` | да | Латиница, цифры, дефис: `tabel`, `kpi-dashboard`. Не меняется после публикации. |
| `name` | да | Название продукта, как в программе. |
| `status` | да | `available` — можно скачать или запросить. `soon` — в разработке: бейдж «В разработке». Описание и список «что умеет» видны. `kind` и `price` для `soon` не обязательны; цену и «Платно» такой карточке не ставь, пока продукта нет в продаже. |
| `tagline` | да | Одна фраза до 90 знаков: зачем продукт. |
| `kind` | для `available` | `free` — бесплатный (золотая кнопка), `paid` — платный. У `soon` можно не указывать: без `kind` карточка не попадает в фильтры «Бесплатные» и «Платные». |
| `price` | для `available` | «Бесплатно», «По запросу», «от 3 000 ₽ в месяц». Мелко под кнопкой. |
| `action.href` | для `available`; для `soon` — если кнопка ведёт куда-то | Бесплатный — страница релизов (`…/releases/latest`), не файл конкретной старой версии. Платный — якорь вроде `#offer` или `mailto:`. Для `soon` — только полный `mailto:R.SH.69.73@yandex.ru?subject=…`: тему письма закодируй в URL. Другой адрес, телефон и мессенджеры не ставь. Нет `action` — кнопка неактивна, текст «Скоро». |
| `action.label` | для `soon`, если есть `action` | Текст кнопки. Для заявки о запуске: «Сообщить о запуске». У доступного продукта по умолчанию «Скачать бесплатно» или «Запросить». |
| `description` | нет | До 360 знаков: два-три коротких предложения. |
| `features` | нет | Массив из 1–4 строк «что умеет». Каждая строка до 120 знаков. На баннере — маркированный список. Нет массива — список не рисуется. |
| `markLabel` | нет | 2–4 символа поверх знака, например `ЗС` или `KPI`. |
| `accent` | нет | Цвет акцента из палитры сайта: `#d4af7a`, `#e2c292`, `#355c8a`, `#6f95cf`, `#c7ccd3`, `#2f7d5b`. |
| `meta` | нет | Системные требования, размер — мелко под кнопкой рядом с ценой. |
| `image`, `imageAlt` | нет | Скриншот и его описание. |

## Правила витрины

- Каждая программа на витрине приведена к стандарту бренда: `sistema-poryadka-brand/CHECKLIST.md`. Пока не приведена — статус `soon`: карточка уже с текстом, бейдж «В разработке».
- Заявка о запуске уходит только письмом на R.SH.69.73@yandex.ru. Оплаты, корзины и формы сбора почты на сайте нет.
- В текст не добавляй функции из планов, цифры эффекта, сроки запуска и интеграции, которых нет в описании продукта.
- Тот же `catalog/products.json` будут читать программы — для блока «Другие продукты «Системы Порядка»». Поэтому внешние ссылки в `action.href` — полные (`https://…` или `mailto:…`).
