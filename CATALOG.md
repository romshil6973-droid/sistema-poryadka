# Как добавить продукт на витрину

Витрина на лендинге собирается из одного файла — `catalog/products.json`. Каждый продукт — баннер: картинка, название, короткое описание и одна кнопка («Скачать бесплатно» или «Запросить»). Страницу править не нужно.

## Шаги

1. Если есть скриншот — положите его в `assets/products/<id>.jpg` (ширина ~1600 px, JPEG). Без скриншота на баннере будет знак «Системы Порядка».
2. Добавьте запись в массив `products` в `catalog/products.json`. Порядок в файле = порядок на странице.
3. Проверьте: `node scripts/check-catalog.mjs`. Он скажет, если что-то забыто или текст не помещается.
4. Закоммитьте и отправьте — сайт обновится сам.

## Образцы

Бесплатный:

```json
{
  "id": "tabel",
  "name": "Табель",
  "kind": "free",
  "price": "Бесплатно",
  "status": "available",
  "tagline": "Учёт рабочего времени без Excel",
  "description": "Одно-два предложения: что делает и для кого.",
  "meta": "Windows 10 и 11 · 90 МБ",
  "image": "assets/products/tabel.jpg",
  "imageAlt": "Окно программы «Табель» со списком сотрудников",
  "action": { "label": "Скачать бесплатно", "href": "https://github.com/romshil6973-droid/sistema-poryadka/releases/download/tabel-v1.0.0/Tabel-Setup-1.0.0.exe" }
}
```

Платный:

```json
{
  "id": "kpi-dashboard",
  "name": "KPI-дашборд",
  "kind": "paid",
  "price": "По запросу",
  "status": "available",
  "tagline": "План, выручка и ПДЗ менеджеров на одном экране",
  "action": { "label": "Запросить", "href": "#contact" }
}
```

Заглушка (продукт ещё не готов, кнопка неактивна):

```json
{ "id": "zaslon", "name": "Заслон", "status": "soon", "tagline": "Скоро на витрине" }
```

## Поля

| Поле | Обязательно | Что писать |
| --- | --- | --- |
| `id` | да | Латиница, цифры, дефис: `tabel`, `kpi-dashboard`. Не меняется после публикации. |
| `name` | да | Название продукта, как в программе. |
| `status` | да | `available` — можно скачать или запросить; `soon` — заглушка «Скоро», кнопка неактивна. |
| `tagline` | да | Одна фраза до 90 знаков: зачем продукт. |
| `kind` | для `available` | `free` — бесплатный (золотая кнопка), `paid` — платный. У заглушки можно не указывать. |
| `price` | для `available` | «Бесплатно», «По запросу», «от 3 000 ₽ в месяц». Мелко под кнопкой. |
| `action.href` | для `available` | Бесплатный — прямая ссылка на установщик в GitHub Releases; платный — `#contact`. |
| `action.label` | нет | Текст кнопки. По умолчанию «Скачать бесплатно» или «Запросить». |
| `description` | нет | До 180 знаков. |
| `meta` | нет | Системные требования, размер — мелко под кнопкой рядом с ценой. |
| `image`, `imageAlt` | нет | Скриншот и его описание. |

## Правила витрины

- Каждая программа на витрине приведена к стандарту бренда: `sistema-poryadka-brand/CHECKLIST.md`. Пока не приведена — заглушка `soon`.
- Тот же `catalog/products.json` будут читать программы — для блока «Другие продукты «Системы Порядка»». Поэтому внешние ссылки в `action.href` — полные (`https://…`).
