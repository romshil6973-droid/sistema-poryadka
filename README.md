## Оргструктура

Бесплатная программа для схемы подчинения и печати на лист А4. Windows 10 и 11, без интернета и без регистрации. Файлы остаются в папке «Документы\Оргструктура».

Скачать: [последний релиз](https://github.com/romshil6973-droid/sistema-poryadka/releases/latest). На странице релиза — `Orgstruktura-Setup-….exe` (установщик) или `Orgstruktura-Portable-….exe` (без установки). [Все версии](https://github.com/romshil6973-droid/sistema-poryadka/releases).

Установщик пока не подписан. Если Windows пишет «неизвестный издатель»: «Подробнее» → «Выполнить в любом случае».

## Как устроен сайт

Витрина продуктов собирается из `catalog/products.json`. Как добавить продукт — [CATALOG.md](CATALOG.md). Проверка: `node scripts/check-catalog.mjs`.

GitHub Pages отдаёт корень ветки `main`. Своего workflow в репозитории нет: после мёржа PR и пуша в `main` сайт обновляет встроенный `pages-build-deployment`.
