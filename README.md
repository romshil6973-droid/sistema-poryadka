# Система Порядка

Сайт и загрузки программ «Системы Порядка» — структура управления результатом.

- Сайт: https://romshil6973-droid.github.io/sistema-poryadka/
- Загрузки: вкладка [Releases](https://github.com/romshil6973-droid/sistema-poryadka/releases)

## Оргструктура

Бесплатная программа для схемы подчинения и печати на лист А4. Windows 10 и 11, работает без интернета и регистрации.

Windows может предупредить, что издатель неизвестен: установщик пока не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Для тех, кто ведёт сайт

Витрина продуктов собирается из `catalog/products.json`. Как добавить продукт — [CATALOG.md](CATALOG.md).
